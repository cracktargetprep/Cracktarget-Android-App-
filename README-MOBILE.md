# Install and test CrackTarget on Android

Download the APK from the completed **Build CrackTarget Android APK** Actions run or use the supplied APK. Extract the APK first if downloaded in an Actions ZIP. Install it on a test device or a separate Android profile. APKs signed with a different certificate require a clean install and can affect existing app-local state if you uninstall an older build.

1. Tap **Account**, then **Sign in with Google**. In your browser, sign in with a CrackTarget student account, confirm the displayed account and tap **Open CrackTarget**.
2. Confirm the correct customer account appears in the app. Open an existing purchased test, complete a test attempt in the designated test workflow, then confirm the result after relaunch.
3. Sign out and confirm Account renders the sign-in screen again. Check cancellation and retry. Verify gesture and three-button navigation, payment return in a sandbox, and an authorized private PDF or ebook download.

This is an internal test APK. Play distribution requires a separately signed Android App Bundle and Play Console approval.
